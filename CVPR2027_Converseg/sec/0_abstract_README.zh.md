# 摘要

**源文件：** `0_abstract.tex`  
**方法简称：** DL-OPD（亦称 ConverOPD）  
**建议英文题：** *Learning from Its Own Mistakes: Dual-Level On-Policy Distillation for Conversational Image Segmentation*

---

会话式图像分割（Conversational Image Segmentation, CIS）要求模型依据自然语言中的抽象意图、空间关系、事件、功能可供性以及物理安全约束，输出像素级掩码。ConVerSeg-Net 等近期基线通过融合稠密分割先验与视觉–语言模型（VLM）的推理能力，为该任务建立了有力基础，但其训练仍主要依赖**固定数据分布**与**静态、离策略监督**：学生不会围绕自身正在产生的错误获得定向纠正，数据引擎也不会随学生能力变化调整采样与生成策略。

本文假设：**最有价值的监督并非来自教师对固定样本的重复输出，而是来自教师对当前学生真实错误的纠正，并据此决定下一批最值得生成与训练的数据。** 据此提出**双层在策略蒸馏（Dual-Level On-Policy Distillation, DL-OPD）**。

在**预测层（Mask-Policy OPD）**中，我们将非自回归分割表述为掩码状态策略。学生先产生当前掩码提议；冻结教师在该学生状态下给出语义与几何纠正，并在像素概率、边界几何与中间表示上联合蒸馏。进一步引入 **Iterative-to-Single-Pass Collapse**，将训练期多步纠错能力压缩回单次前向推理。

在**数据层（Data-Policy OPD）**中，我们依据学生在五类会话概念、负向提示、边界与校准维度上的实时误差画像，自适应选择图像、提示生成算子与样本配比；经多级教师验证后，样本进入**短生命周期 Hard Buffer**。

我们将围绕学生诱导状态相对固定/历史状态、误差驱动数据相对随机扩增、以及两层 OPD 的互补收益开展系统实验，并评估抽象概念分割、负向提示抑制、边界质量与单遍部署效率。DL-OPD 旨在为会话式视觉理解与具身感知中的高价值数据闭环提供可复现的方法基础。
